# 人生日历

用“一年一格”展示人生进度。填写出生日期、预期寿命和退休年龄后，页面会生成
对应数量的年份格子：

- 青色：已经走过的年份。
- 黄色：当前所在的年份，点击可进入本月视图。
- 浅灰色：退休前、尚未到来的年份。
- 浅绿色：从退休年龄开始的年份。

出生日期、预期寿命和退休年龄位于设置弹窗。点击主卡片标题旁的“设置”打开，
保存后关闭弹窗即可查看更新后的格子。点击当前黄色格子时，年视图后退缩小，
月视图从该格子的位置展开；再次点击月视图中的黄色日期时，月视图缩回原来的
格子位置，年视图随后恢复。

标题下方的进度条按完整人生铺开：左侧青色是已经走过的时间，睡眠与退休前的
工作从最右端向里侵占，中间绿色是可自由支配的余生。绿色再按退休边界分成两段，
退休后自由时间叠加斜线纹理。进度条下方同时列出各段折合年数及其在余下生命
中的占比。每日睡眠和工作时长可在设置弹窗中调整，默认各为 8 小时/天。

可以切换“虚岁显示”：实岁从 0 岁开始，虚岁从 1 岁开始。当前黄色格子显示
保留一位小数的准确年龄。退休位置也会随年龄模式变化，并按格子内显示的年龄
匹配退休年龄；例如默认生日与 65 岁退休时，实岁从 2064 年开始退休，虚岁从
2063 年开始退休。

还可以添加最多 12 个自定义类型。每个类型包含名称、开始边界、结束边界、颜色
和展示方式，可选择按覆盖月份填充或在格底添加彩色下划线。边界可使用年月、年龄
或 `now+N` 相对月份。
年视图右侧会列出所有阶段；悬停或聚焦某个阶段时，对应年份会进一步高亮。
设置弹窗中可拖动左侧把手调整阶段顺序，也可聚焦把手后使用上下方向键移动。

“已走过、现在、退休前、退休”四种默认状态会显示在设置弹窗中，并作为最底层
颜色；右侧阶段列表只展示自定义阶段。自定义填充阶段只覆盖实际月份，未覆盖的
月份才会露出默认底色。悬停底部图例中的默认状态时，会高亮对应的年份层级。
当前年份始终显示黄色的“现在”样式，即使该年份同时被自定义填充阶段覆盖。

## 启用

在本地账本配置 `benacount-local.yaml` 中启用：

```yaml
plugins:
  life_calendar:
    enabled: true

navigation:
  routes:
    life_calendar:
      group: plugins
      position: last
      quick_menu: true
```

打开 `/ledger/<owner>/<ledger>/plugins/life_calendar`，或在账本侧边栏选择
“人生日历”。

## 配置

设置保存在当前账本的：

```text
plugins/life_calendar/config.json
```

```json
{
  "version": 1,
  "birthday": "1999-03-07",
  "lifeExpectancy": 85,
  "retirementAge": 65,
  "sleepHours": 8,
  "workHours": 8,
  "showNominalAge": false,
  "customTypes": [
    {
      "id": "study",
      "label": "求学",
      "startMonth": "2005-03",
      "endMonth": "2017-06",
      "display": "fill",
      "color": "#6587c7"
    }
  ]
}
```

- `birthday` 使用 `YYYY-MM-DD`，不能晚于今天。
- `lifeExpectancy` 是预期寿命对应的最终年龄，范围 1–120 岁。实岁模式从
  0 岁排到预期寿命，虚岁模式从 1 岁排到同一最终年龄。
- `retirementAge` 是退休年龄，范围 0–预期寿命。
- `sleepHours` 是余下生命中每天用于睡眠的小时数，范围 0–24，默认 8。
- `workHours` 是从今天到退休每天用于工作的小时数，范围 0–24，默认 8；
  每日睡眠与工作之和不能超过 24 小时。旧配置缺少这两项时自动使用 8。
- 年格每行 10 个。`showNominalAge` 控制虚岁显示；`false` 时省略 0 岁格，
  将出生年并入 1 岁格，首格显示年龄 1 和出生年至次年（例如 `1999-2000`），
  退休年份也按实岁计算；设为 `true` 时所有显示年龄前移一年，退休年份同步
  前移一年。
  预期寿命始终表示最终年龄，不受虚实岁切换影响，输入 90 时最后一格仍为
  90 岁。
- `customTypes` 最多 12 项；`startMonth` 和 `endMonth` 保存为 `YYYY-MM`，
  两端都包含。设置弹窗中输入年龄时会按当前实岁/虚岁开关换算成年月，并在
  输入框和阶段列表中同时显示年龄。开始边界可填 `start` 表示从第一格开始，
  结束边界可填 `end` 表示覆盖到最后一格；`start` 固定显示为 0 岁，`end` 的
  年龄根据预期寿命和虚岁开关计算。`now+3` 表示当前月份往后 3 年，会以相对
  表达式保存，并在每次打开或重新计算时按当天日期动态解析；也支持 `now` 和
  `now-3`。颜色使用 6 位十六进制值。
- 自定义填充阶段按实际覆盖的月份在年格中横向定位；同一年内的多个阶段会分别
  占据对应月份。没有自定义阶段覆盖的月份，露出下层默认状态的颜色。跨年阶段
  会在每一年分别参与定位。悬停阶段列表时，只增强对应阶段所占的分段，其余
  区域使用与其他未高亮阶段相同的弱化效果。
- `display` 可为 `fill`（按月份比例填充）或 `underline`（格底彩色下划线）；旧配置
  未设置时默认为 `fill`。旧配置中的 `startAge` / `endAge` 仍可读取，并会
  自动转换为年月区间。

页面修改会即时预览；点击“保存设置”后才会写入 JSON。保存时会校验文件
revision，避免覆盖同时在别处发生的修改。

页面支持夜间模式，跟随应用的主题设置自动切换配色。
