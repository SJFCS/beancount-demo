# FIRE 模拟器

FIRE 模拟器用一组可复现的参数，评估从当前年龄到预期寿命期间投资组合耗尽的风险。所有计算在浏览器中完成。点击“保存方案”后，参数会写入当前账本目录的 `plugins/fire_calculator/plan.json`，再次打开时自动载入；该文件随账本仓库一起版本管理，可以保存多套命名方案并在页面顶部切换。点击“重置”会重新读取已保存方案并丢弃尚未保存的修改；若尚无保存方案，则保留当前参数并提示。设置面板的显示状态、年度明细的隐藏列和资产变化瀑布图的隐藏行会保存在浏览器本地，并按账本分别记忆。插件不会修改账本文件，也不会把参数或结果上传到服务器。

## 功能

- 设置当前年龄、退休年龄、预期寿命和初始投资资产；当前年龄可直接填写岁数，也可切换为填写出生年份、由当年年份自动计算岁数。年龄与资产输入框支持直接输入，也可按住左右拖动微调。
- 所有数值输入框均支持直接输入，也可按住左右拖动微调。
- 设置面板以悬浮弹窗形式从屏幕中央弹出：左侧是五个分类菜单，右侧显示当前分类的参数设置，点击遮罩、右上角关闭按钮或按 Esc 收起；结果显示区始终占满整页宽度。
- 配置股票、债券和现金的目标比例，并设置再平衡周期。
- 设置股票和债券的预期年化回报、年化波动率及税率，并配置组合年化管理费；现金按通胀增长，并可设置超过通胀的实际收益（可为负）。
- 自定义定期收入和支出：收入与支出分列展示，分别添加收入或支出项目，可设置名称、每月金额、起止年龄以及是否跟随通胀；新增卡片默认自同列上一张卡片的结束年龄后一年开始、至退休结束。每张定期收支卡片默认折叠，头部紧跟名称显示可直接编辑的每月金额输入框、生效年龄区间标签和是否跟随通胀的图标标记，通胀标记直接显示当前通胀率；点击生效年龄标签即可展开年龄设置，再点一次收起，点击卡片其他区域不会展开。拖动排序只在同列内进行；“上一张卡片”指同一列（同一类型）中排在该卡片前的一张，展开卡片时会显示上一张卡片的名称与年龄区间。起止年龄可通过双滑块或直接输入数字调整；开始年龄可勾选“自当前年龄”“自退休”“自上个卡片开始年龄”或“自上个卡片结束年龄”，结束年龄可勾选“至退休”“至生命结束”或“至上个卡片结束年龄”，三者互斥；跟随上一张卡片时，上一张卡片的结束年龄变化会自动传递到当前卡片及后续模拟。起止年龄的上限随预期寿命调整，调低预期寿命时自动收窄到新寿命内。生活支出同样按年龄区间录入，可分段设置不同水平，不再使用固定的月支出字段。
- 分别添加一次性收入或支出；金额按发生年龄计入，可设置是否跟随通胀。一次性现金流同样按收入、支出分列展示，拖动排序只在同列内进行。
- 定期收支与一次性现金流卡片可按住标题前的手柄拖动调整顺序，也可在聚焦手柄后用上下方向键调整。
- 每张收入、支出与一次性现金流卡片都可以临时停用（不参与模拟但保留参数），再次点击即可恢复。
- 支持多套方案：页面顶部方案下拉菜单可切换方案，每项后带铅笔图标可重命名、垃圾桶图标可删除，菜单末尾“＋ 新建方案”只打开未保存的新建页面，暂定名为下一顺位的“方案 N”，保存后才加入方案列表。重命名后失焦或按 Enter 会自动保存名称，按 Esc 取消；确认删除后会立即保存方案列表；每套方案的参数独立保存，切换时自动载入该方案参数并运行模拟（相同参数会直接复用上次的计算结果）。有未保存修改时切换或新建会先弹出自绘确认窗口询问是否丢弃。
- 选择月度随机或手动收益率；随机模式支持固定随机种子，便于复算和比较方案。
- 选择提款策略：固定实际金额、按组合比例提款，或使用可配置阈值和上下限的护栏策略；护栏触发线可按首个正净提款年度自动建立的初始率计算，也可手动指定提取率。
- 查看成功率、全部路径的期末中位数，以及包含全部路径的 P10/P25/P50/P75/P90 分位带；存在未成功路径时，在“固定购买力提款”卡片中用橙色显示耗尽年龄的最小值、P10、P25、中位数、P75、P90 和最大值，不再额外绘制第二张耗尽年龄分布图。
- 结果图表按两行两列组织：“全部路径 · 资产余额的可能路径”与“全部路径 · 所选年龄的资产分布”在宽屏左右并排并自动等高；“当前路径 · 第 N 条 · 收入、支出与资产提取”与“当前路径 · 第 N 条 · 年度资产变化与明细”在下一行左右并排并自动等高；窄屏按两两配对顺序纵向排列并恢复各自自然高度。四张图共用当前路径、年度滑块和今日购买力／名义金额状态，并在卡片头部右侧显示当前年龄区间和金额口径切换；资产余额图在绘图区上方展示 P50 中位数及 P10–P90、P25–P75 区间，年度现金流图在绘图区上方展示年度结余、储蓄率、资产提取占支出比例和年末资产可覆盖年数，折线绘图区会与右侧瀑布图等高填充。资产余额图和年度现金流图共用悬停年份，鼠标悬停任一张时同步显示同一年度的悬浮详情，鼠标所在图表的悬浮框跟随指针，另一张图在其对应年度位置显示。当前路径、年度与当年摘要组成浮动底栏并固定显示在结果区域底部，当前路径按钮左栏保留路径标签和路径编号，右栏在自动护栏模式下列出“当前路径护栏初始率”、退休日资产和期末资产，其他策略则列出“当前路径退休首年净提款率”、退休日资产和期末资产；护栏初始率按建立基准当年的年初资产计算，退休首年率按退休日资产计算，两者都不是退休期平均值或全部路径 P50。点击按钮会弹出完整路径图表，支持关闭按钮、点击遮罩或 Esc 收起；拖动年度时两张走势图、全部路径资产分布图、资产变化瀑布图和明细表同步更新。年度现金流图支持点击图例隐藏收入、支出、资产提取或投资盈亏，隐藏状态按账本保存在浏览器中。四张卡的年龄区间标签都与今日购买力／名义金额切换放在卡片头部右侧的同一操作区，资产变化摘要会按卡片宽度自动换行并保持完整可见。年度资产变化原先位于瀑布图标题处的重复切换已移除。独立的年度收支与资产明细卡片放在图表网格下方并占满整行，现金流项目可在“年在上”和“月在上”之间切换，月均按当年实际模拟月份计算，资产余额不计算月均；今日购买力／名义金额和金额主次顺序都按账本保存在浏览器中。表头在该卡片的滚动区域内固定，横向滚动时年龄列也保持固定。明细表与资产变化卡片共用今日购买力／名义金额状态，列显示与行显示控件使用内联 SVG 展开箭头。动态提款策略的明细表提供“净提款率”和“消费调整”列；“净提款率”标出护栏初始率与退休首年率，两率在同一年建立且数值一致时为绿色，否则为橙色；消费调整以绿色上箭头显示消费上调、红色下箭头显示消费下调，并同时展示年度差额、相对计划支出的比例和月均调整额。资产分布图把该年龄所有路径的真实余额分箱，柱高表示区间内路径占全部路径的比例，并叠全部路径 P10/P25/P50/P75/P90；资产已耗尽的失败路径计入零资产区间，零资产部分用橙色从基线向上叠加，摘要中的“此年龄已耗尽”占比和条数也使用橙色。悬浮可查看区间内路径数、占比和累计占比。余额悬浮框显示实际最大值、P90、P75、中位数、P25、P10 和实际最小值；年度现金流图悬浮框显示收入、支出、资产提取和投资盈亏。明细表可核对收入、支出、投入、提取、盈亏、管理费、收益税与年初资产，年初资产附带“较去年”变动；计划生活费、策略消费预算和实际支出分别列出。资产变化瀑布图支持隐藏单项行，隐藏设置按账本保存在浏览器中。
- “全部路径 · 提款率与期末资产”用 SVG 散点图展示每条完整路径：自动护栏模式下横轴为“护栏初始率”，固定、组合比例及手动护栏模式横轴为“退休首年净提款率”，纵轴为期末资产；橙色点表示中途耗尽，绿色点表示覆盖整个规划期。图表上方同时列出与横轴同一指标的 P10、P25、P50、P75、P90，并画出对应竖线：P10/P90 是两侧尾部参考，P25/P75 是中间区间边界，P50 是中位数，表示一半路径低于它、一半高于它。点击底部当前路径按钮会以弹层打开该图表，关闭按钮、点击遮罩或 Esc 均可收起。默认选择最接近同一指标 P50 的路径；点击散点或拖动“浏览完整路径”滑块可切换路径，滑块也按同一指标排序。自动护栏中未建立初始率的路径排在末尾但仍可查看，并明确显示数量；它们不进入散点，避免被误当成 0% 样本。在绘图区横向拖出透明选框只放大提款率轴，纵向拖框只放大资产轴，两轴均有拖动时同时放大；缩放后坐标刻度和可见散点会随视窗重算，超出当前视窗的分位线自动隐藏，图表右上角会悬浮显示“重置缩放”，点击即可返回全图。当前选择会同步更新两张年度走势图、资产变化瀑布图、明细表和期末资产摘要。系统只为当前路径按需回放完整月度流水，不会预生成全部路径明细，也不会把逐年分位数拼接成一条路径。失败路径只显示到失败当月，未支付金额单列缺口，后续年份不再模拟；手动模式只有一个情景。
- 动态提款提醒中的“查看消费降幅明细”可展开“成功路径 · 消费下调幅度”卡片，默认折叠。柱形图按每条成功路径退休后相对当年计划消费曾达到的最大降幅分组，并列出全部曾下调路径的最大降幅、发生年龄、最终月消费和最终消费占当年计划的比例；路径不分页，统一按最大降幅从高到低排列，在固定高度表格内滚动，点击路径编号即可切换下方年度明细。该卡片只统计最终走到规划终点的路径；最大降幅描述历史低点，最终月消费描述最后一个模拟年度，两者不是同一指标。最终月消费为该年度策略消费预算，不是实际支付金额；失败路径不计入分母，也不参与降幅分位。

## 启用

在当前账本的 `benacount-local.yaml` 中加入：

```yaml
plugins:
  fire_calculator:
    enabled: true

navigation:
  routes:
    fire_calculator:
      group: plugins
      position: first
      quick_menu: true
```

然后打开账本侧边栏中的“FIRE 模拟器”，或访问：

```text
/ledger/<owner>/<ledger>/plugins/fire_calculator
```

## 计算口径

模拟始终按月处理现金流，随机模式只决定回报的抽样频率。每个定期收支项目按起止年龄生效，年龄区间包含开始和结束年龄；某个年龄的生活支出等于该年龄所有生效支出项目之和，可用于“大城市租房几年、回乡后减少”等分段安排。每个月先收取定期收入，再支付该年龄的生活支出和一次性支出，不足以支付时，该路径从该月起记为失败。其余资产产生投资回报、扣除管理费，并在指定月份按目标比例再平衡。成功指模拟期间每个月都能覆盖现金流，最后一个月支付完成后余额恰好为零仍计为成功。

生活支出没有单独的固定字段：每个年龄的生活支出等于该年龄所有生效支出项目之和，没有生效支出项目的年龄不计生活支出。勾选“至退休”或“至生命结束”的定期收支会随计划退休年龄或预期寿命自动确定结束年龄；勾选“至上个卡片结束年龄”时会动态采用上一张卡片的有效结束年龄。保存时若 `plan.json` 已被其他编辑器修改，会提示版本冲突并要求重新载入后再保存。

金额输入和默认结果均以今天的购买力表示，结果可切换为未来名义金额。消费随累计通胀增长；现金按通胀增长，并叠加手动指定的实际收益；年化管理费按月等效扣除。税率采用简化模型：股票和债券分别对本年度正的累计投资收益（未扣管理费）征税一次，亏损不跨年抵扣；不模拟出售成本税基、个人所得税或现金利息税。

- **月度随机**：将年化预期收益与波动率换算成月度对数正态回报，每月独立抽样；股票、债券与通胀的随机冲击彼此独立。
- **手动指定**：用固定年化股票收益、债券收益和通胀率计算一条确定性路径。

提款策略决定退休后的消费预算：

- **固定实际金额**：按各年龄计划的生活支出消费，并随通胀增长。
- **组合比例**：每年以期初投资组合余额乘以年度提款率设定消费预算；退休后不再跟随计划支出，市场下跌时消费会下降。
- **护栏策略**：以各年龄计划支出为起点，每年按年初资产的净提款率评估一次。触发线基准可选择“护栏初始率”，即首个正净提款年度同一条路径的实际净提款率，也可手动指定提取率；手动率从退休首年开始生效。默认消费下调触发线为基准率的 120%，消费上调触发线为基准率的 80%；越过触发线后单次调整消费 10%，最低和最高消费默认限制为当年计划支出的 50%–150%。两个触发线、单次调整幅度、最低消费和最高消费均可配置。定期收入会计入护栏评估使用的年度净提款率；一次性收支仍按发生年龄独立计入现金流。

成功率只衡量能否覆盖当前策略下的消费预算；组合比例和护栏策略可能通过降低消费获得较高成功率，比较方案时也要关注退休后的可用消费。最终月消费指标显示消费预算的分布，成功率不代表整个退休期都能维持最初的生活水平。顶部最终余额中位数和余额分位带都使用所有路径，失败路径从失败后起按零计入，因此两者在规划终点使用同一统计口径。

消费下调统计只使用成功路径。每条路径的“最大降幅”等于退休后各年度 `1 − 策略消费预算 ÷ 当年计划生活支出` 的最大值，消费高于计划的年度按 0 计；它不把通胀造成的计划变化算作主动下调。“最终月消费”取最后一个模拟年度的实际口径策略预算，并同时显示它占当年计划支出的比例。卡片中的降幅分位只统计曾下调的成功路径，若没有路径下调则显示为空。

顶部指标按策略选择口径。自动护栏模式显示“全路径护栏初始率”：对每条路径取退休后首个正净提款年度，以该年年初资产为分母，分子为当年策略消费预算扣除常规收入后的年度净提款额；退休首年收支抵消的路径不会建立初始率，直到后续首次出现正净提款。卡片数值为已建立初始率路径的 P50，并在卡内同时展示最小值、P10、P25、P75、P90、最大值和已建立条数；没有路径建立初始率时显示“—”，不会用 0 填补。固定、组合比例及手动护栏模式继续显示“全路径退休首年净提款率”：以每条路径退休当日资产为分母，分子为退休首年策略消费预算扣除当期常规收入后的年度净提款额，最低按 0 计。两类指标都不包含一次性收支，策略消费预算也不是实际支付支出。单一路径时分别简化为“护栏初始率”和“退休首年净提款率”。

护栏明细中的“净提款率”按当年年初资产计算，分子为当年策略消费预算（进入当年护栏判断的支出预算）扣除常规收入后的年度净提款额，不包含一次性收支。自动模式在退休后第一个正净提款年度建立护栏初始率；若退休首年没有正净提款，护栏初始率会在更晚的年度建立，此时明细表会同时展示退休首年率与护栏初始率，并用橙色标出差异。手动模式直接使用填写的护栏率；实际退休首年率与手动率不一致时，明细表同样用橙色标出。计划生活费、策略消费预算、支出和净提款率列标题旁的问号会在悬停或键盘聚焦时显示对应口径；净提款率的提示会按当前路径基准率及护栏配置动态计算并展示上调线与下调线。顶部指标是全部路径的 P50，明细表比较的是当前路径，不应把两个数字直接当作同一口径。消费调整金额是当前策略预算相对当年计划的累计偏离；绿色上箭头和红色下箭头只表示本年实际执行的上调或下调，没有箭头而仍显示金额时表示此前调整继续保留、本年未再调整。退休前不应用提款策略，因此消费调整显示“—”；不随通胀调整的定期支出按固定名义金额计入计划与策略预算。

明细表新增“当年通胀”列，展示当前路径逐年的累计价格涨幅：它是该路径月度随机通胀抽样的年化结果，长期平均接近设定的年通胀率，但单年可因随机波动明显偏高或偏低，个别年份可能远超设定值。名义金额口径下，跟随通胀的支出同比增幅等于当年通胀；今日购买力口径下计划生活费保持不变。手动模式没有随机抽样，“当年通胀”固定等于设定的年通胀率。消费调整列出现的百分比是护栏策略对计划支出的调整比例，与通胀无关。

耗尽年龄按失败发生的月份计算（`开始年龄 + 失败月份 / 12`），分位点使用所有未成功路径。最小值表示最早耗尽，最大值表示最晚耗尽。

明细表中的“投入资产”和“从资产提取”是当月收入与消费及一次性收支抵扣后的转入、转出；收益税另列，不重复计入收支。投资盈亏含股票、债券与现金收益，尚未扣除管理费和收益税。“投资年化”按每个月组合收益链式计算时间加权收益率，剔除收入、支出、投入与提取对分母的影响；今日购买力口径下再按当年实际通胀折算实际收益率，名义金额口径显示名义收益率，不足一年按实际投资月份折算，管理费和收益税仍以单独列展示。明细表上方的“年末资产构成”按当前路径、当前年度和金额口径列出股票、债券、现金的年末余额、占组合总额的比例及各自的时间加权年化；进度条表示年末结构，各行年化与“投资年化”一样为管理费和收益税前口径，合计行展示整体组合收益率。失败年份的资产余额归零，年化按中止前已完成的投资月份计算。今日购买力口径按每笔现金流发生时的累计通胀折算，并单列现有资产的通胀购买力变化，使期初资产加减各项流水后能对上期末资产。失败当月若资金不足，明细优先记入生活费支出，再记入一次性支出，余款列为未付缺口；这些明细不改变原有模拟的成功判定。

默认参数用于演示，结果是对所填假设的估算，不能预测未来市场表现。
